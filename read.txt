1. EXECUTIVE SUMMARY & PURPOSE
--------------------------------------------------------------------------------
The Mahalaxmi Borewell Financial Management application is an enterprise-grade,
offline-first mobile billing, quotation, invoicing, and accounting solution
specifically tailored for borewell drilling contractors, pump installation
specialists, electrical fittings, and agricultural/industrial water supply businesses.

Key Objectives:
- Eliminate manual paper billing and static dotted line templates.
- Maintain a sequential, system-controlled quotation and invoice register.
- Multi-step structured quotation generation wizard (5 distinct stages).
- Render pixel-perfect, authentic printed quotation documents with user-entered
  specifications seamlessly placed into table rows.
- Two-tier workflow: Quotation creation -> Invoice conversion with final adjustment.
- Track business revenues, material expenses, technician charges, and client tasks.
- Provide local cryptographic security without external cloud or internet reliance.

3. OFFLINE-FIRST ARCHITECTURAL PRINCIPLES
--------------------------------------------------------------------------------
1. Zero Cloud Dependency:
   The application requires no backend server, no REST API, no Firebase, and
   no cloud database. All data operations are executed locally on device storage.

2. Atomic Transactions:
   Every quotation, bill, or invoice generation creates the header and all related
   line items inside a single SQLite transaction (`db.runTransaction`). If any step
   fails, the entire operation is automatically rolled back.

3. Two-Tier Document Architecture:
   - QUOTATION (Estimate / Bill): Generated during initial client assessment via
     a 5-step wizard. Stored in `bills` and `bill_items`.
   - INVOICE (Tax / Final Bill): Converted from an accepted quotation or created
     directly. Stored as an immutable snapshot in `invoices` and `invoice_items`
     with independent adjustment capabilities (`FinalInvoiceAdjustmentScreen`).

4. Dual-Mode Visual Rendering:
   - EDIT MODE: Clean card-based entry form with dedicated numeric, text, switch,
     and dropdown inputs replacing every dotted line.
   - VIEW MODE (`QuotationDocumentView`): The exact Mahalaxmi Borewell printed
     quotation document (light beige #FAF7F0 paper, maroon #7A1C1D banner,
     sacred verse, phone numbers, table columns, terms, and signature box)
     with zero dotted placeholders and all entered specifications rendered.

9. OPERATIONAL & BUILD INSTRUCTIONS
--------------------------------------------------------------------------------
1. Prerequisites:
   - Node.js 18+
   - Java Development Kit (JDK 17)
   - Android SDK (Platform 34 / 35, Build Tools 35.0.0)
   - PowerShell / Windows Terminal

2. Development Server:
   From project root:
   npx react-native start --reset-cache

3. Run On Connected Android Device / Emulator:
   npx react-native run-android

4. Clean Gradle Build:
   cd android
   .\gradlew clean
   cd ..

5. Production Release APK Compilation:
   cd android
   .\gradlew assembleRelease
   The output APK will be generated at:
   android/app/build/outputs/apk/release/app-release.apk

6. Run Automated Test Suites:
   npm test
   Executes 29 comprehensive unit tests across 3 suites covering financial
   calculations, currency translation, database startup, and billing concurrency.

7. Run TypeScript Compilation Audit:
   npx tsc --noEmit
   Verifies 100% strict type conformance across all TS/TSX source files.
